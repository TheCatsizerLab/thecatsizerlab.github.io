The product

The game and the system behind it.

Tri Spells Arena is the most systems-heavy project in the portfolio. It combines fast 3D combat, spell interactions, authoritative server logic and gameplay readability under multiplayer constraints.

The project is useful as a freelance reference because it demonstrates work on gameplay feel, networking, collisions, VFX, performance and debugging inside a non-trivial codebase.

▣

Authoritative multiplayer

A Go backend validates collisions, hits and projectile interactions so multiplayer combat stays consistent.

▣

Spell combat systems

Different spell families, combined spells, walls, AOE attacks and support abilities all need clear gameplay behavior.

▣

Performance focus

The build is being optimized for stable fights and clear visual readability during multiplayer action.
