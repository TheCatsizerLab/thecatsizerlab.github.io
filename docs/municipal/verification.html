Valmer-sur-Rive — Verification report

Independent fictional municipal portal, developed by TheCatsizerLab. Verification date: 24 November 2026.

This is a functional local demonstration. It does not provide real municipal services, server authentication or shared storage. Automated checks do not establish full RGAA compliance.

Browser journeys

19 complete Playwright checks passed: global search, directory filters, agenda/calendar, event export, room booking and duplicate-slot protection, appointments, reports, contact simulation, map, content preview/draft/publication, cross-tab updates, page and directory changes, event and alert management, manual availability, citizen status/notifications and demo reset.

Layouts and accessibility

Eight representative page types captured at 1920 × 1080, 1440 × 900, 768 × 1024 and 390 × 844: 32 captures. No document-wide horizontal overflow or broken images. 71 seeded routes also received a mobile overflow smoke check; the four generic lookup templates are exercised by the interactive journeys. Static article, event and directory details were additionally checked with JavaScript disabled. No JavaScript errors were reported.

Axe checks using WCAG 2 A/AA and WCAG 2.1 AA tags found zero violations on the eight representative page types at 1440 and 390px. Keyboard menu opening, Escape closure and focus were tested. A full screen-reader, user and RGAA audit has not been performed.

Five domain unit tests passed. The visual availability calendar also passed its dedicated mobile interaction check. The portfolio and project case study passed 12 additional viewport checks, gallery opening/closure and 78 static-page link/metadata checks. All ten projects remain present in the requested order. All 44 final layout captures were visually reviewed.

Limitations

Local simulations are not a security or availability guarantee for a production municipality. Reservation storage is not transactional across real users. Manual checks and automated tests cannot certify regulatory compliance. Browser storage can be cleared or blocked. Images show real places used to illustrate an imaginary territory.
